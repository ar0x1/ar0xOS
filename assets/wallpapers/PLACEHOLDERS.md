## Phase 1 — canonical wallpaper paths (art delivered in Phase 6; KEPT in Phase 7)

These are the **exact paths** every config, PKGBUILD and theme references, so later
assets can be dropped in without editing configs.

**Phase 6 status:** `ar0x-neon-grid.png`, `ar0x-void.png` and `ar0x-circuit.png`
EXIST as deterministic PNGs generated by `tools/gen-desktop-assets.sh` (pure
zlib encoder, no ImageMagick, no licensing ambiguity, ~250 KB total).
`assets/sddm/ar0x/background.png` is generated the same way.

**Phase 7 decision (ADR-022, RISK-040 CLOSED):** these generated geometric PNGs
**ARE the v0.1 wallpapers** — they are kept, not replaced. Phase 7 delivered a
REAL `ar0x-cursors` XCursor theme (closing the cursor half of RISK-040) and
finalised the GRUB / Plymouth / syslinux BOOT art from the official SVG
logomark. Committing large photographic/AI art would add licensing ambiguity
and risk the 2.2 GB ISO gate for no structural benefit. A vector/photographic
wallpaper set is a **v0.2** item. Regenerate with:

```bash
./tools/gen-desktop-assets.sh   # no root, no network, byte-reproducible
```

`ar0x-grub-bg.png` is **NOT** generated here: Phase 4 already ships the
authoritative GRUB background at `assets/grub-theme/ar0x/background.png`, which
`tools/build-kernel.sh --sync` copies into the ISO. Do not create a second one.

### Sources used for the v0.1 wallpapers
- Generated in-house by `tools/gen-desktop-assets.sh` from the `config/versions.env`
  palette (ADR-015): cyan perspective grid, magenta horizon, circuit traces.
- No third-party assets, no network fetch, no fonts are embedded. CC BY-SA 4.0
  as ar0x-authored artwork; the generator source IS the provenance.

### Optional sources for a FUTURE (v0.2) art set
- Generate in-house with Inkscape / Blender using `assets/logo/ar0x-logo.svg` as the base.
  **Do not replace the current PNGs without re-running `configure-desktop.sh --sync`.**
- CC0/CC BY geometry textures from ambientCG or Poly Haven for the noise/circuit layers.
- Unsplash / Pexels CC0 neon city photography only as a **layer**, never as the whole wallpaper.
- Keep each final PNG under 4 MB; the ISO has a 2.2 GB hard gate (PROJECT_PLAN.md §7).
- Ship a `LICENSE` per asset. ar0x-authored artwork = CC BY-SA 4.0.

### Do not
- Do not use a 4K PNG for the GRUB background (GRUB's PNG parser is memory-limited).
- Do not reference `~/wallpapers` or any user-home path from `/etc/skel` configs.
