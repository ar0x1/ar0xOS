# GRUB 2 gfxmenu theme for ar0x 0.1.0 "Neon Root".
# PHASE 4 created the theme; PHASE 7 finalised the branded art and layout.
#
# Installed at TWO target paths (both are needed):
#   ISO      : /boot/grub/themes/ar0x/theme.txt  — archiso 92 copies every
#              non-*.cfg file from <profile>/grub/ to <ISO>/boot/grub/
#              (mkarchiso::_make_bootmode_uefi.grub, `files_to_copy`).
#   Installed: /usr/share/grub/themes/ar0x/theme.txt — used by grub-mkconfig
#              via GRUB_THEME in config/default/grub.
#
# ⚠️ NO *-font keys, BY DESIGN (Phase 7 confirmed this, not deferred):
#    archiso 92 runs `grub-mkstandalone --themes=""` and embeds NO font in the
#    EFI binary. A named font here would make gfxmenu fall back unpredictably.
#    GRUB's built-in font is used. archiso/grub/grub.cfg has a guarded
#    `loadfont ar0x-16.pf2` that activates ONLY if a font is ever shipped.
#
# PHASE 7 LAYOUT: the official 512x512 logomark + "ar0x" caption are drawn INTO
# background.png by tools/gen-theme-assets.sh (shared geometry from
# tools/lib/ar0x_logo.py, master assets/logo/ar0x-logo.svg). The two Phase 4
# header labels were REMOVED so the boot menu never overlaps the logo:
#   background.png : mark at y=20..206, caption at y=218..260, rule at y=690
#   boot_menu      : top=34% (261px) .. 70% (538px)
#   progress_bar   : top=78% (599px)
#   footer label   : top=84% (645px)
#
# Palette (ADR-015, config/versions.env):
#   void #07090F | surface #11151F | cyan #00E5FF | magenta #FF2E88
#   lime #A8FF60 | text #D7E0EE | muted #6B7891
